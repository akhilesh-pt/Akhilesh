## Run a project locally

**Requirements:** Python 3.10+ and a terminal (PowerShell, Command Prompt, or VS Code terminal).

```powershell
git clone https://github.com/akhilesh-pt/Akhilesh.git
cd Akhilesh
python Projects/hello.py
```

To run a different project, replace `hello.py` with another filename from the table. Some projects ask for input in the terminal.
